# The iOS shell

No browser on iPhone or iPad can use Bluetooth: Apple requires all of them to run
on WebKit, and WebKit has no Web Bluetooth. Opening Brain Trails in Safari there
will never reach a Muse, whatever the page does. The way in is the **Brain Trails
app**: a WKWebView on the deployed site plus a CoreBluetooth bridge
([Capacitor](https://capacitorjs.com) with `@capacitor-community/bluetooth-le`).

It is the same webapp, not a second one:

- `capacitor.config.ts` points the web view at the deployment (`server.url`). The
  site has a BFF, so it cannot be a static bundle; a release of the site is a
  release of the app. `shell/` only holds the offline page.
- `src/lib/muse/nativeBluetooth.ts` presents the plugin as the `Bluetooth` object
  `BluetoothMuse` already takes. One driver, one set of decoders, one capture
  format. `bluetoothTransport()` in `device.ts` picks `web`, `native` or none.
- The plugin's JavaScript is imported on demand, only inside the shell.

| Where                             | How the Muse is reached          |
| --------------------------------- | -------------------------------- |
| Chrome / Edge on desktop, Android | Web Bluetooth, nothing installed |
| iPhone / iPad                     | the Brain Trails app             |
| Safari, Firefox (any platform)    | not possible; upload a file      |

## Build and run

Needs a Mac with Xcode. `ios/` is a generated Xcode project that is committed;
`ios/App/App/capacitor.config.json` is regenerated by `cap sync` and ignored.

```bash
npm install
npm run ios:sync          # write the config into the Xcode project
npm run ios:open          # open it in Xcode, pick a device, Run
```

Point a build at another environment with `BT_SHELL_URL`, e.g. a local dev server
reachable from the device (`BT_SHELL_URL=http://192.168.1.20:3000 npm run ios:sync`).

The iOS **simulator has no Bluetooth radio**: there the bridge answers
`BLE unsupported`. Pairing can only be tested on a real device.

## Signing and distribution

- **Free Apple ID** (Xcode > Settings > Accounts, then the App target > Signing &
  Capabilities > your Personal Team): installs on devices plugged into the Mac,
  expires after 7 days, at most 3 apps. Enough for our own iPads; trust the
  developer on the device under Settings > General > VPN & Device Management.
- **Apple Developer Program** (99 USD/year): TestFlight and the App Store, which
  is what testers and users need. An App Clip -- opened from a link or QR with no
  install -- is the closest iOS allows to "just open the site", and also needs it.

The bundle id is `work.lumentis.braintrails`; change it in `capacitor.config.ts`
and the Xcode target before the first store submission, not after.
